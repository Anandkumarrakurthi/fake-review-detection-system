About FakeReviewGuard

AI-powered solution for detecting fraudulent reviews in e-commerce

Project Overview

Online marketplaces rely heavily on customer reviews to influence purchasing decisions, making them a critical factor for both consumers and sellers. However, a significant portion of reviews may be fake, biased, or misleading, resulting in distorted product perception and reduced trust.

This project presents an intelligent Fake Review Detection Model designed to automatically identify suspicious or fraudulent reviews using advanced machine learning techniques. The system leverages a rich set of features extracted from product reviews, including sentiment score, star rating, review length, verified purchase status, and helpful vote count.

Methodology

Data Collection & Preprocessing
  • Dataset with 6,327 Amazon product reviews
  • Feature extraction from review metadata
  • Handling missing values and outliers
  • Data normalization using StandardScaler
Feature Engineering
  • Sentiment score calculation
  • Review length and word count analysis
  • Verification status encoding
  • Anomaly pattern detection rules
Model Training
  • Random Forest Classifier (200 estimators)
  • XGBoost Classifier (gradient boosting)
  • Logistic Regression (baseline model)
  • Ensemble approach with majority voting
Evaluation & Validation
  • 70-15-15 train-validation-test split
  • Accuracy, Precision, Recall, F1-Score
  • ROC-AUC curve analysis
  • Cross-validation and hyperparameter tuning

Key Features

Sentiment-Rating Consistency Check

Detects inconsistencies between review sentiment and star rating

Verification Status Analysis

Flags unverified purchases with extreme opinions

Review Length Anomaly Detection

Identifies suspiciously short or long reviews

Engagement Pattern Analysis

Evaluates helpful vote patterns relative to review content

Real-time Prediction

Instant classification with confidence scores

Interactive Visualizations

Comprehensive dashboards with Plotly charts
